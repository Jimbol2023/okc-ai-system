# Governance Agent Module Checklist

- [ ] Purpose is defined.
- [ ] Owner is assigned.
- [ ] Data sources are listed.
- [ ] Source tracking is required.
- [ ] Assumptions are labeled.
- [ ] Prohibited claims are documented.
- [ ] Approval requirements are defined.
- [ ] Tool Registry dependencies are listed.
- [ ] Safe Auto Mode policy is defined.
- [ ] Audit events are defined.
- [ ] Monitoring signals are defined.
- [ ] Failure and fallback behavior is defined.
- [ ] Tests cover no-provider-call and no-external-action boundaries.
