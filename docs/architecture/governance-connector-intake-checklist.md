# Governance Connector Intake Checklist

- [ ] Official API reviewed.
- [ ] Terms of Service reviewed.
- [ ] Robots.txt or scraping policy reviewed where applicable.
- [ ] Authentication method documented.
- [ ] Required permissions documented.
- [ ] Secrets storage plan defined.
- [ ] Rate limits documented.
- [ ] Cost per call documented.
- [ ] Retry policy documented.
- [ ] Health check plan documented.
- [ ] Fallback tool registered.
- [ ] Approval policy configured.
- [ ] Audit events configured.
- [ ] Kill switch defined.
- [ ] No live activation before approval.
