# Governance Approval Matrix

| Action | Default Requirement | Notes |
| --- | --- | --- |
| Publish content | Human approval | Includes website, social, GBP, newsletters, and press. |
| Send email | Human approval | Consent and compliance required. |
| Send SMS | Human approval | Consent, DNC, and sender identity required. |
| Make phone call | Human-owned | AI may prepare notes only. |
| Generate offer | Human approval | Requires verified property facts. |
| Generate contract | Human approval | Legal review boundary applies. |
| Delete record | Admin approval | Prefer soft deletion. |
| Merge duplicates | Human approval | Preserve lineage. |
| Activate connector | Admin approval | Requires Tool Registry entry. |
| Change automation | Admin approval | Requires audit and rollback plan. |
| Change budget | Admin approval | Requires ROI and risk review. |
| Use external API | Admin approval | Requires credentials, limits, and monitoring. |
