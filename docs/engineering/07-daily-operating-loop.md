# Daily Operating Loop

The daily operating loop turns AI OS data into safe, revenue-focused work.

## Loop

1. Daily Mission gathers internal/read-only signals.
2. AI COO routes work to departments.
3. Department managers assign AI employees.
4. AI employees produce internal-only outputs.
5. Approval / Safety reviews risky or external-facing work.
6. CEO approves, rejects, defers, or requests changes.
7. Approved work produces an outcome.
8. Memory records lessons and blockers.
9. KPIs inform the next daily mission.

## Daily Output Types

- CEO briefing
- internal work order
- lead data gap
- CRM cleanup task candidate
- seller follow-up plan
- marketing draft
- design brief
- SEO recommendation
- GBP trust task
- acquisition review packet
- finance gap note
- connector blocker report
- memory lesson
- approval packet

## Non-Negotiable Boundaries

The loop does not authorize external execution by itself. Execution requires a separate exact-action approval path and governed policy.
